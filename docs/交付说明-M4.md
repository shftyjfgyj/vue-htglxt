# 交付说明 · M4 个人中心与关注管理

## 1. 交付内容

### 后端

| 变更 | 文件 | 说明 |
| --- | --- | --- |
| 上传中间件抽取 | `src/modules/upload/upload.middleware.ts` | 统一图片白名单（jpg/png/gif/webp）、2MB 限制、年月分目录、`publicUrlOf()`、`removeLocalUpload()` |
| 头像接口 | `POST /api/v1/users/me/avatar` | 登录即可用（不需要额外权限点）；更新 `users.avatar` 并**删除旧的本地上传文件**；写审计日志 `update_avatar` |
| 菜单种子 | `sql/002_seed.sql` | 新增「个人中心」分组：个人资料 `/profile`、关注管理 `/profile/follows`（所有登录用户可见） |

### 前端

| 页面/能力 | 位置 | 说明 |
| --- | --- | --- |
| 头像上传 | `views/profile/ProfileView.vue` | 头像预览 + 上传（前端 `before-upload` 自定义上传，成功后刷新 profile） |
| 关注管理 | `views/profile/FollowView.vue` | 三个页签：我的关注 / 我的粉丝 / 互相关注；支持取消关注、回关；空状态提示 |
| 路由与菜单 | `router/index.ts`、`sql/002_seed.sql` | `/profile/follows` 路由 + 后端菜单驱动侧栏图标（Avatar / Star） |
| API 客户端 | `api/user.ts` | 新增 `uploadAvatar(file)` |

## 3. 与老系统对照

| 老系统问题 | 现在 |
| --- | --- |
| 头像接口读写不存在的 `ev_users.user_pic`，且 `this.saveAvatarHistory` 必崩 | 头像落到 `users.avatar`，上传走统一中间件，无历史表依赖 |
| 头像 base64 走 JSON（body 限制 50MB） | multipart 上传 + 2MB 限制 + 白名单 |
| 上传目录无限增长 | 更换头像时自动删除旧文件；旧文件为外部 URL 时安全跳过 |
| 关注管理页接口 404、模板变量未定义而白屏 | 关注数据来自 `/api/v1/me/*`，页面有加载/空状态，按钮按页签语义区分 |
