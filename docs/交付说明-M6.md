## 2. E2E 抓出的 3 个真实缺陷（已修复）

| # | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | 编辑角色侧栏仍显示「系统管理」空壳分组 | 菜单按权限过滤只过滤子项，没有剪掉因此变空的分组 | menu.service 增加剪枝：无 path 且无子项的节点不返回 |
| 2 | 管理员搜索后列表恒为「共 0 条」 | 查询串里的 onlyMine=false 被 z.coerce.boolean() 解析成 true（Boolean('false') === true） | 新增 QueryBoolean 预处理，显式识别 true/false/1/0 |
| 3 | 全文检索搜「管理 / 系统 / 脚手架」为 0 结果，关键词含 + 时直接 500 | ngram 解析器带 * 前缀通配对中文多字词不可靠；BOOLEAN MODE 操作符未过滤 | 中文不加通配、过滤操作符，并在 0 命中时自动回退 LIKE |

补充修复：E2E 反复登录触发登录限流（20 次/10 分钟）导致全量失败 → 阈值改为 LOGIN_RATE_LIMIT 可配置，且 E2E 改用 storageState 复用登录态。

## 4. 运行 E2E

```bash
# 前置：后端 dist 已构建、前端 dist 已构建（npm run build）
npm --prefix apps/web run test:e2e          # 无头
npm --prefix apps/web run test:e2e:headed   # 看真实浏览器操作
```

Playwright 会自动启动 API（放宽登录限流）与前端 preview；报告输出到 apps/web/e2e-report/。
