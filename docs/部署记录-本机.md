## 4. 开机自启与自愈

已安装到**当前用户启动文件夹**（`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`）：

- `htglxt-api.vbs` → 隐藏窗口启动后端
- `htglxt-nginx.vbs` → 隐藏窗口启动 nginx
- `htglxt-watchdog.vbs` → 隐藏窗口常驻守护进程（`deploy/windows/watchdog.ps1`，每 5 分钟检查端口，不通就重新拉起，日志写 `logs/watchdog.log`）

**登录 Windows 后自动生效**；若想立即生效，直接运行上面的「启动全部」脚本。

### 为什么没用计划任务 / PM2

| 方案 | 本机结果 | 结论 |
| --- | --- | --- |
| 计划任务（`Register-ScheduledTask` / `schtasks /create`） | `Access is denied`（非管理员被组策略限制） | 不可用，改启动文件夹 |
| PM2 守护 | 能启动应用，但守护进程随启动它的会话结束被回收，`pm2 list` 变空 | 本机不可靠；Linux/容器环境仍推荐 PM2（`docker/ecosystem.config.cjs` 保留） |
| 启动文件夹 + VBS + 守护脚本 | 可用、无需任何管理员权限 | **本次采用** |

在真正的服务器（有管理员权限）上，建议改回标准做法：

```powershell
# Windows 管理员 PowerShell
Register-ScheduledTask -TaskName 'htglxt-api' -Action (New-ScheduledTaskAction -Execute 'C:\Program Files\nodejs\node.exe' -Argument 'apps\server\dist\index.js' -WorkingDirectory 'C:\htglxt') -Trigger (New-ScheduledTaskTrigger -AtStartup) -Settings (New-ScheduledTaskSettingsSet -RestartCount 3 -RestartInterval (New-TimeSpan -Minutes 1)) -User 'SYSTEM' -RunLevel Highest
```

## 5. 部署过程中发现并修复的 2 个真实问题

### 5.1 `.env` 按当前工作目录查找，导致从别处启动读不到配置

现象：从仓库根执行 `node apps/server/dist/db/migrate.js` 报 `Access denied for user 'root'@'localhost' (using password: NO)`。

根因：`dotenv.config()` 默认按 `process.cwd()` 找 `.env`，而 PM2 / 计划任务 / systemd 的 CWD 通常不是 `apps/server`。

修复：`src/config/env.ts` 改为**显式从包根目录加载**，失败才回退 CWD。修复后从任意目录启动都能读到配置（已验证）。

### 5.2 PM2 日志路径按 cwd 解析

现象：`logs/` 配的是仓库根，实际落到 `apps/logs`。

修复：`docker/ecosystem.config.cjs` 的日志路径改为 `../../logs/api-*.log`（相对 cwd=apps/server）。

## 6. 上线后待办（重要）

1. **改 admin 密码**：当前是种子默认口令，登录 → 个人中心 → 修改密码（会使全部会话失效）。
2. **数据库口令**：本机 MySQL root 仍是弱口令 `123456`（且这台机器还有其它项目在用同一个 MySQL，改口令会影响它们）。若要严格生产，建议为本项目单独建库用户：
   ```sql
   CREATE USER 'htglxt'@'127.0.0.1' IDENTIFIED BY '<强口令>';
   GRANT ALL PRIVILEGES ON htglxt_v2.* TO 'htglxt'@'127.0.0.1';
   FLUSH PRIVILEGES;
   ```
   然后改 `apps/server/.env` 的 `DB_USER` / `DB_PASSWORD` 并重启后端。
3. **防火墙**：如需其它机器访问 8080，需管理员执行 `New-NetFirewallRule -DisplayName 'htglxt-http' -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow`。
4. **定时备份**：把 `scripts/backup-db.ps1` 挂到任务计划程序（管理员）或手动定期执行。
5. **监控**：`/metrics` 已被 nginx 屏蔽对外，Prometheus 请直连 `127.0.0.1:3001/metrics` 并带上 `.env` 里的 `METRICS_TOKEN`（请求头 `x-metrics-token`）。
6. **HTTPS**：本机为 HTTP；正式对外建议在 nginx 上加证书（`docker/nginx-host.conf` 注释里给了 certbot 用法）。

## 7. 以后要改用 Docker（可选）

装好 Docker Desktop 后，在同一仓库执行：

```bash
cd docker
# docker/.env 必填 JWT_ACCESS_SECRET / JWT_REFRESH_SECRET / MYSQL_ROOT_PASSWORD / CORS_ORIGIN
docker compose up -d --build
docker compose --profile tools run --rm migrate
# 访问 http://本机:8080 （WEB_PORT 可调）
```

注意：Docker 版自带独立 MySQL 容器（数据卷 `mysql-data`），与本机 MySQL 的 `htglxt_v2` **不是同一份数据**；如需迁移，用 `scripts/backup-db.ps1` 导出后导入容器。
