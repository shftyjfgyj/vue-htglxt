# 交付说明 · M8 互动增强（收藏 / 我的收藏与点赞 / 评论定位 / 阅读页能力）

> 参考了掘金、CSDN、Medium、WordPress 等成熟内容系统的常见能力，挑出对后台内容管理最有价值的几项实现。

## 1. 文章收藏

| 层 | 内容 |
| --- | --- |
| 数据库 | 新增 `article_favorites` 表（`(article_id,user_id)` 唯一、`idx_favorite_user` 便于「我的收藏」排序查询）；`articles` 增加冗余列 `favorite_count` |
| 后端 | `POST /api/v1/articles/:id/favorite`、`DELETE /api/v1/articles/:id/favorite`，与点赞一致：事务内 `INSERT IGNORE` + 计数联动，**幂等** |
| 详情 | `GET /api/v1/articles/:id` 增加 `favorited` 与 `favoriteCount` |
| 前端 | 阅读页底部操作区新增圆角「收藏 · N」按钮，选中态为品牌色，点击即时反馈并写入我的收藏 |

迁移文件：`apps/server/sql/004_m8.sql`（幂等，含列存在性判断与菜单种子）。

## 2. 我的收藏 / 我的点赞

- 后端：`GET /api/v1/me/favorites`、`GET /api/v1/me/likes`，同一套返回结构（文章信息 + `markedAt` 收藏/点赞时间 + 三个计数），按时间倒序分页。
- 前端：新增页面 **我的内容库**（`/profile/library`，菜单挂在「个人中心」下）——顶部两个标签页（我的收藏 / 我的点赞），表格展示文章、作者、状态、数据、收藏/点赞时间，支持「阅读」与「取消收藏 / 取消点赞」。

## 3. 评论 → 文章 + 定位到该评论

- 评论管理里「文章」列与新增的「查看」按钮都会跳到 `/content/articles/{articleId}/view#comment-{id}`。
- 阅读页支持 hash 锚点：评论渲染时带 `id="comment-{id}"`；进入页面后自动滚动到该评论并**高亮 2.6 秒**；若评论未通过审核或已删除，则提示「该评论当前不可见」，不会白屏。
- 评论节点加了 `scroll-margin-top`，滚动后不会被顶栏遮住。

## 4. 阅读页增强（参考成熟内容系统）

| 能力 | 说明 |
| --- | --- |
| 阅读进度条 | 吸附在内容区顶部的 3px 渐变条，跟随 `.admin-main` 滚动容器实时计算 |
| 本文目录 | 自动从正文 `h1~h3` 生成（补锚点 id、按层级缩进、可折叠），点击平滑滚动 |
| 阅读时长 | 按「中文 400 字/分钟 + 英文 200 词/分钟」估算，显示在元信息行 |
| 相关文章 | `GET /api/v1/articles/:id/related`：同分类或共享标签的已发布文章，按共享标签数 + 浏览量排序，阅读页底部展示 |
| 复制链接 | 一键复制当前文章地址（浏览器不支持时给出提示） |

## 5. 接口清单（新增）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST / DELETE | `/api/v1/articles/:id/favorite` | 收藏 / 取消收藏（幂等，登录即可） |
| GET | `/api/v1/me/favorites?page&pageSize` | 我的收藏 |
| GET | `/api/v1/me/likes?page&pageSize` | 我的点赞 |
| GET | `/api/v1/articles/:id/related?limit=5` | 相关文章推荐 |

## 7. 过程中修掉的一个问题

截图脚本为规避登录限流而复用了 E2E 保存的登录态，但 **access token 只有 15 分钟**：App 会自动刷新，脚本的裸 fetch 不会，导致阅读页截图静默丢失。已改为「先调 `/auth/profile` 校验，失效则重新登录」。
