# UI 设计说明（现代风格改版）

> 改版前截图：`ui-shots/before/`　改版后截图：`ui-shots/after3/`
> 复现命令：`node scripts/ui-shots.mjs <label> [用户名] [密码]`（默认 editor 账号，自动跳过无权限页面）

## 1. 改版目标与结论

| 改版前的问题 | 改版后的做法 |
| --- | --- |
| 侧栏是扁平深蓝（#1f2d3d），顶部一条蓝色，观感陈旧 | 深空灰渐变侧栏 + 品牌光晕 + 激活项渐变药丸 + 左侧指示条 |
| 主色直接用 Element 默认蓝 #409EFF，缺少辨识度 | 统一换成 **Indigo 品牌色阶**（#6366F1 / #4F46E5），语义色改为柔和版 |
| 卡片是默认 1px 灰边 + 直角方块，密度低 | 16px 大圆角 + 双层柔和阴影 + 悬停微抬升；表头浅灰、去掉竖分隔线 |
| 表格满格边框、列多导致固定列遮挡内容 | 两行单元格（标题 + 分类/标签）、状态列带数据副行、操作列常用动作平铺 + 低频动作收进「更多」下拉 |
| 标签用实心原色（#13CE66/#FF7D00），刺眼 | 药丸标签：浅底 + 同色文字 + 色点，尊重数据里的原始颜色 |
| 登录页只有一张白卡片浮在蓝底上 | 左右分栏：品牌叙事区（渐变+光晕+能力要点）+ 表单区（演示账号一键填充） |
| 看板是四个白卡片 + 一串标签墙 | 渐变欢迎横幅（含实时指标）、图标芯片指标卡（带进度条）、奖牌榜单、可折叠权限面板 |

## 3. 设计令牌（`apps/web/src/styles/theme.scss`）

- **圆角**：`--radius-xs 6px`（标签）/ `--radius-sm 8px`（按钮、输入框）/ `--radius-md 12px`（下拉、弹层）/ `--radius-lg 16px`（卡片）/ `--radius-xl 20px`（横幅）
- **阴影**：`--shadow-xs`（静态）/ `--shadow-sm`（卡片）/ `--shadow-md`（悬停、弹层）/ `--shadow-brand`（主按钮品牌光）
- **字体**：`--font-sans` 系统字体栈（Inter → Segoe UI → PingFang SC → 微软雅黑），`--font-mono` 用于权限码、账号等
- **Element Plus 覆盖**：直接改写 `--el-color-primary` 及其 light-3/5/7/8/9 阶梯、语义色阶梯、`--el-border-radius-base`、`--el-text-color-*`、`--el-table-*`、`--el-box-shadow*`

> 关键点：**只改令牌、不改组件**。所有 Element Plus 组件自动跟随，新增页面零成本保持一致。

## 8. 深色模式

- 顶栏右上角新增**主题开关**（月亮/太阳图标），切换即生效并写入 `localStorage: htglxt.theme`。
- **首次访问跟随系统** `prefers-color-scheme`；之后以用户选择为准。
- **首屏防闪烁**：`main.ts` 在 `createApp` 之前就把 `dark` class 打到 `<html>` 上，刷新不会出现亮→暗跳动。
- 实现方式是**令牌翻转**：`theme.scss` 里 `html.dark { … }` 覆盖 `--surface/--canvas/--line/--text-*/--chip-*`，同时引入 Element Plus 官方 `dark/css-vars.css`，因此所有组件（表格、弹窗、下拉、分页、消息）自动适配。
- 为了方便主题化，业务代码里**不再直接用 `--ink-900` 之类的结构性颜色当文字色**，改用语义令牌：`--text-strong / --text-body / --text-muted / --text-faint / --chip-bg / --chip-brand-*  / --hover-bg / --header-bg`。

## 9. 表格列宽记忆

可复用组合式函数：`apps/web/src/composables/useTableColumns.ts`

```ts
const cols = useTableColumns('articles', {
  标题: { minWidth: 260 },   // 未拖拽时自适应撑满
  作者: { width: 96 },
  操作: { width: 190 }
});
```

```html
<el-table border stripe @header-dragend="cols.onHeaderDragend">
  <el-table-column v-bind="cols.colProps('作者')" prop="authorName" label="作者" />
</el-table>
<el-button v-if="cols.isCustomized.value" @click="cols.reset()">重置列宽</el-button>
```

- 存储键：`htglxt.table-cols.<表格名>`，以**列 label** 为键（label 唯一且比 property 更适合纯展示列）。
- 拖拽过的列记住宽度；未拖拽的列继续用声明的 `width` / `minWidth`（`minWidth` 列仍会自适应）。
- 出现自定义后工具栏显示「重置列宽」，一键清除。
- 已接入：文章列表、用户列表。其它表格复制上面三行即可。

> 实现细节：Element Plus 的**列宽拖拽依赖 `el-table` 的 `border` 属性**。为了同时保留拖拽能力和现代观感，表格保留 `border` 但把竖线设为 `border-right-color: transparent`，只留行分隔线。

## 12. 写文章 / 编辑文章页改版

### 改版前的问题（见 `ui-shots/before-editor/12-editor.png`）

1. 所有字段挤在一个表单里：右侧「分类/标签/封面」被压成一条缝，下拉框很窄。
2. 标题是普通输入框，没有文档感；页面标题只是卡片头里的一行小字。
3. 保存/提交按钮在**页面最底部**，写完正文还要往下滚才能提交。
4. 封面只有一个「上传封面」小按钮，没有预览、没有尺寸提示。
5. 左栏窄、右栏空，整页大量留白。

### 改版后的结构（见 `ui-shots/final-editor/` 与 `final-editor-dark/`）

```
┌─ 吸顶操作条 ────────────────────────────────────────────────┐
│ ← 写文章 / 编辑文章      [状态标签] 最近更新 …               │
│                            [版本历史] [保存草稿] [保存并提交审核] │
├───────────────────────────────┬───────────────────────────┤
│ 稿纸（左，自适应）              │ 发布设置（右，320px 吸顶） │
│  · 大标题输入（25px 无边框）    │  · 分类 / 标签             │
│  · 摘要（弱化副标题）           │  · 封面（虚线拖拽框 + 预览）│
│  · 分割线                      │  · 发布流程（四步说明）     │
│  · 富文本编辑器（min-height 380）│  · 实时统计（字数/标签/封面）│
└───────────────────────────────┴───────────────────────────┘
```

| 改版点 | 说明 |
| --- | --- |
| 吸顶操作条 | 主操作永远可见；返回按钮、状态标签、审核意见（驳回时高亮）都在这里 |
| 文档式稿纸 | 标题 25px 无边框、摘要作为次要副标题、Quill 编辑器去外框只留工具栏分隔线 |
| 右侧设置栏 | 分类/标签/封面/流程说明/统计分卡片呈现，`position: sticky` 跟随滚动 |
| 封面交互 | 空态是虚线框（点击上传 + 格式与大小提示），已上传时显示预览 + 悬停「更换封面」遮罩 + 可移除 |
| 实时统计 | 正文按「中文字符 + 英文单词」粗略计数，标签数与封面状态一眼可见 |
| 校验保留 | 标题与正文仍走 `el-form` 规则（校验失败提示显示在字段下方） |
| 响应式 | ≤1100px 设置栏落到正文下方；≤700px 按钮平分整行、标题缩小 |
| 深色适配 | 全部使用语义令牌；Quill 工具栏图标、引用块、代码块随主题变色 |

### 兼容性

页面上被自动化依赖的文案与结构保持不变：`请输入标题`、`选填，用于列表展示` 两个占位符、`保存草稿` / `保存并提交审核` 按钮名、`.ql-editor` 编辑区、版本历史抽屉与 diff 弹窗。

| 长文回顶麻烦 | 右下角**回到顶部**圆形按钮，滚动超过 420px 才出现，悬停变品牌渐变 |
| 深色下正文几乎看不见（粘贴内容带内联 color） | 深色模式下强制正文使用主题色，并对标题/引用/代码分别给色，避免「黑底黑字」 |

作者卡里的「关注作者」直接复用关注关系接口：关注后可在「关注动态」看到 TA 的文章；自己的文章不显示该按钮。
