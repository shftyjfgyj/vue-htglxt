# 数据库设计（htglxt_v2）

MySQL 5.7+ / utf8mb4。所有表统一 `id int unsigned auto_increment`、`created_at`、`updated_at`、`deleted_at`（软删）。

## M1/M2 已落地

| 表 | 说明 |
| --- | --- |
| users | 用户（+ status、last_login_at、soft delete） |
| roles | 角色（code 唯一，is_system 保护内置角色） |
| permissions | 权限点（code 形如 `user:create`，module + type） |
| role_permissions | 角色-权限 |
| user_roles | 用户-角色（唯一） |
| menus | 菜单（parent_id 树，permission_code 关联权限，驱动前端动态菜单） |
| refresh_tokens | 刷新令牌（存哈希，支持吊销与强制下线） |
| login_logs | 登录日志（成功/失败、IP、UA） |
| operation_logs | 操作审计（who/when/ip/method/path/status/detail） |

## M3 预览（表已建，接口待开发）

| 表 | 说明 |
| --- | --- |
| categories | 文章分类 |
| tags | 标签 |
| articles | 文章（+ summary、view/like/comment_count、publish_at、audit_status、软删） |

## 设计要点

1. 计数冗余：articles.view_count / like_count / comment_count 避免列表页 N 次 COUNT。
2. 审计：所有写操作经 `audit()` 落 operation_logs，记录 before/after 摘要。
3. 权限：管理员角色使用通配符 `*`；其余按权限码精确匹配。
4. 软删：查询层统一过滤 `deleted_at IS NULL`。
