## 2. 关键业务规则（已由冒烟测试断言）

1. **越权范围**：无 `article:audit` 权限的用户只能看到/操作自己的文章；有权限者可按条件查全量，也可勾选「只看我的」。
2. **状态机**：0 草稿 → 1 待审核 → 2 已发布 / 3 已驳回 → 4 已下线；待审核期间禁止编辑（400）；提交审核幂等保护；驳回后可再次提交。
3. **版本快照**：每次更新先把旧内容写入 `article_versions`（版本号递增），恢复版本时把当前内容存为新版本，实现「可回溯、不丢数据」。
4. **评论入口**：只有已发布（status=2）的文章可以被评论；评论计数通过事务与 `articles.comment_count` 保持一致。
5. **点赞幂等**：重复点赞不会重复计数（`INSERT IGNORE` + 计数联动）。
6. **关注约束**：不能关注自己（400）；`/api/v1/me/following|followers|mutual` 直接给当前用户，修正老系统 `/users/me/*` 404。
7. **上传安全**：仅 jpg/png/gif/webp，单文件 ≤2MB，随机文件名 + 年月目录，非图片返回 400。
