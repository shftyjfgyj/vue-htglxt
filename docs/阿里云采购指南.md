## 1. 账号与实名（第一步，1 天）

1. 注册阿里云账号（手机号），完成**个人实名认证**（身份证 + 人脸，几分钟）。
2. **域名实名**与**账号实名**是两件事：账号实名后才能买资源；域名还要单独做域名持有者实名（1~3 天审核），**备案前必须完成**。
3. 建议同时开通「费用中心 → 预算与预警」，设一个 **¥200/月** 预警，避免忘记关机被计费。

## 3. 域名购买（10 分钟 + 1~3 天实名）

1. 打开 [万网域名注册](https://wanwang.aliyun.com)，搜你要的名字，加购物车。
2. **注册年限选 1 年**（首年优惠只对首年；先短期试水，续费再考虑多年）。
3. 创建**域名信息模板**（个人：姓名/身份证/邮箱/手机），选它作为持有者。
4. 提交前填「优惠口令」，支付。
5. 支付后立刻做**域名实名认证**（上传身份证），1~3 天通过。

价格（已核实，2026-10）：**新用户首年 .com 35 元、.cn 38 元**，部分套餐赠 CN 域名。

⚠️ **两个坑**：
- **续费价 ≠ 首年价**：.com 续费通常 70~90 元/年 → 打开「自动续费」避免过期被人抢注。
- 域名**转入/转出**有 60 天锁定期，别频繁折腾。

参考：[阿里云万网域名注册新手指南](https://developer.aliyun.com/article/1768101)

## 4. ECS 购买（重点，含机型选择）

### 4.1 逐步操作

1. 控制台 → 云服务器 ECS → **创建实例**。
2. **地域**：选你离用户近的（如华东1-杭州）。**必须与后面 RDS 同地域**，否则只能走公网、又慢又贵。
3. **实例规格**：
   - 省钱首选：**经济型 e（2核2G）**，99 元/年那档；
   - 想宽裕：**通用算力型 u1（2核4G）**，199 元/年（注意页面可能标「企业专享」，个人账号买不到就退而选轻量或按量）；
   - 我们这套（Docker + Node + Nginx + 容器内构建）**强烈建议 2核4G**；2核2G 也能跑，但**构建镜像时容易 OOM**（可用本机构建好再传的办法绕开）。
4. **镜像**：**Ubuntu 22.04 64 位**（不要选 Windows，我们全套是 Linux/Docker）。
5. **系统盘**：ESSD Entry 40G 起步；1 年数据量不大，40~60G 够。
6. **公网 IP / 带宽**：勾**分配公网 IPv4**；带宽选**固定带宽 3~5 M**（我们页面 gzip 后很小，5M 够几十人同时用）。
   - **计费方式**：**包年包月**（备案要求 + 便宜）；按量付费只适合短时测试。
7. **安全组**：新建一个，规则只放 `22`（来源填你的公网 IP/32）、`80`、`443`。**不要**放 3001/3306。
8. **登录凭证**：选**密钥对**（比密码安全）；创建时下载 `.pem` 保存好（丢了要重置）。
9. **购买时长**：**1 年**（活动价都是年付，且备案要求 ≥3 个月）。
10. 提交订单前：确认活动价已生效（¥99 或 ¥199），再看一眼是否有可用优惠券。

### 4.2 为什么推荐「99 计划」那台

- **续费同价**（很多活动机型第二年涨价，这台明确同价）；
- **可申请备案服务码**（备案要求见 §7）；
- 2核2G + 我们把数据库放 RDS → ECS 上只跑 Docker（web+api 两个小容器），日常完全够用。

### 4.3 如果只买到轻量应用服务器

也可以，**轻量同样能申请备案服务码**（已核实）。但要接受：
- 带宽是「峰值 200M + 月流量包」，超流量会限速/计费；
- 不支持弹性公网 IP、不支持挂载多块数据盘等增强能力，**扩容不如 ECS 灵活**；
- CPU 为共享型，构建镜像时更慢。

### 4.4 ECS vs 轻量 一句话结论

> 预算优先 → 轻量 2核4G（199/年）；**长期稳定 + 可平滑扩容 → ECS 经济型 e（99/年）或 u1（199/年）**。我们这个项目推荐 **ECS**，因为要跑 Docker 且以后可能加内存。

## 5. RDS MySQL 购买

### 5.1 逐步操作

1. 控制台 → 云数据库 RDS → 创建实例。
2. **引擎**：MySQL **8.0**；**地域/VPC**：与 ECS **完全一致**（同地域同 VPC → 走内网）。
3. **系列**：**基础版**（单人开发/小流量够用、便宜）；预算允许再上高可用版。
4. **规格**：1核2G 起（我们 QPS 很低）；**存储**：20G 起，勾**ESSD PL1**。
5. **购买时长**：1 年（比月付便宜很多）。
6. 创建后依次做四件事（**缺一个都跑不通**）：
   - **创建数据库**：`htglxt_v2`，字符集 `utf8mb4`，排序规则 `utf8mb4_unicode_ci`（RDS 账号没有建库权限，必须先建）；
   - **创建账号**：例如 `htglxt`，只授权 `htglxt_v2` 的读写；
   - **白名单**：填 **ECS 的内网 IP**（不是公网 IP）；
   - **参数**：确认 `ngram_token_size = 2`（中文全文检索依赖，默认就是 2）。
7. 打开**自动备份**（保留 7~30 天）。

### 5.2 价格

RDS 按「规格 + 存储 + 时长」计费，**我没有拿到可引用的固定价**，请用控制台左上角「价格计算器」按 1核2G/20G/1年 查实际金额（通常在百元级/月，新用户与活动期更低）。

### 5.3 想再省：先用 ECS 自建 MySQL

我们仓库里 `docker/docker-compose.yml`（非 prod 版）自带 MySQL 容器，**零额外成本**先跑起来。代价：备份、调优、升级都要自己做，且 **安全组绝不能开 3306**。真上线我仍建议 RDS —— 数据库是最不该省的那一环。

## 6. SSL 证书（⚠️ 这里我之前的文档写错了，已更正）

### 6.1 真实价格与有效期（已核实，2026-08）

| 类型 | 价格 | 有效期 | 说明 |
| --- | --- | --- | --- |
| 个人测试证书 **免费版** | ¥0 | **90 天** | **每年限领 20 张**；DV；不支持 .edu/.gov 等后缀 |
| 个人测试证书 **Pro** | **¥18**（原价 ¥34） | **6 个月** | DV；含人工客服 |

> ⚠️ **免费证书不是 1 年，是 90 天**。我的 `docs/部署-阿里云ECS与RDS.md` 里原写「1 年」已过时，本文档为准。

### 6.2 申请步骤（免费版，约半小时）

1. 控制台 → 数字证书管理服务（SSL 证书）→ **个人测试证书（免费版）** → 创建证书。
2. 填主域名（`your-domain.com`，可加 `www`），**域名验证方式选 DNS**（我们还没解析也能过）。
3. 按提示到域名解析里加一条 **TXT 记录**；等待验证（几分钟~几小时）。
4. 签发后**下载「Nginx 格式」**压缩包，得到 `xxx.pem` 与 `xxx.key`。
5. 改名放到服务器：
   ```bash
   # 在本地把 pem/key 改名为 fullchain.pem / privkey.pem 后上传
   scp fullchain.pem privkey.pem root@<ECS IP>:/opt/htglxt/deploy/nginx/certs/
   # 服务器上执行（会把 nginx 切到 HTTPS 配置）
   bash deploy/linux/renew-cert.sh
   ```

### 6.3 90 天到期怎么办（三选一，我推荐前两个）

- **方案 A：Let's Encrypt + certbot 自动续期**（零维护）：仓库脚本已支持
  ```bash
  bash deploy/linux/renew-cert.sh --letsencrypt   # 首次签发
  # 之后由 cron 自动续期（脚本内已带 certbot 循环容器）
  ```
- **方案 B：买 Pro 版 ¥18/6 个月**，每半年手动换一次，省心一半；
- **方案 C：继续用免费版**，每 90 天重新下载替换一次（一年 4 次，20 张配额够）——记得把到期日加到手机日历。

参考：[CAS 个人测试证书免费版与 Pro 版对比](https://developer.aliyun.com/article/1759134)、[2026 免费 SSL 证书申请全流程](https://developer.aliyun.com/article/1704934)

## 7. 备案（时间瓶颈，务必先启动）

### 7.1 硬性前提（已核实）

- 必须有一台**阿里云服务器（或云虚拟主机）且购买时长 ≥ 3 个月**，才能获得**备案服务码**；
- 可备案的 ECS 必须是**包年包月 + 有公网带宽的中国内地节点**（没有公网 IP 要先去加带宽）；
- 服务码**默认只能本账号使用**；跨账号授权要求授权方是**企业认证账号**；
- ⚠️ **服务器退款或释放会让备案服务码失效**，备案中千万别退。

### 7.2 步骤

1. ECS 控制台 → 实例详情 → **备案服务码** → 申请（免费）。
2. 控制台 → 备案 → 新增备案：主体信息（个人：身份证、手机、邮箱）+ 网站信息（网站名称别用敏感词）+ **填写备案服务码**。
3. 阿里云初审（1~2 天）→ 提交管局（**7~20 天**，各省不同）→ 通过后收到短信/站内信。
4. 备案通过后，域名解析到 ECS 公网 IP 才能用 80/443 对外服务。

### 7.3 备案期间能做什么

- 服务器可以先装好 Docker、配好 `.env`、把服务跑起来（用 IP 访问自测）；
- RDS 可以照常购买、迁移、联调；
- 证书可以先申请（DNS 验证不依赖解析）；
- **只有「域名解析 + HTTPS 对外」要等备案**。

参考：[阿里云备案服务码使用指南](https://developer.aliyun.com/article/1760577)

## 8. 购买顺序与时间线

```
第 1 天  注册账号 + 实名认证
         ├─ 买域名（35 元）→ 立刻提交域名实名（1~3 天）
         └─ 买 ECS（99/199 元/年，≥3 个月）→ 申请备案服务码 → 提交备案
第 2~3 天 域名实名通过；开始装环境（Docker、拉代码、配 .env、本地跑通页面）
         └─ 买 RDS + 建库/白名单/参数，跑一次迁移验证空系统
第 4~20 天 等管局审核（期间做验收：PDF 报表、图片上传、权限边界都可在 IP 上测）
备案通过  域名解析 → 申请证书 → 切 HTTPS → 跑 healthcheck → 上线
```

## 9. 七个最容易踩的坑

1. **免费证书只有 90 天**（不是 1 年）→ 现在就决定好用 certbot 还是买 Pro。
2. **域名续费 ≠ 首年价**（.com 首年 35，续费约 70~90）→ 开自动续费。
3. **ECS 与 RDS 必须同地域同 VPC**，否则走公网、慢且多花钱。
4. **RDS 要自己先建库**（账号无 CREATE DATABASE 权限）；白名单填**内网 IP**；`ngram_token_size=2`。
5. **安全组只开 22/80/443**，22 限来源 IP；3306/3001 一律不开。
6. **服务器退款会作废备案服务码**；RDS 到期会**释放数据**（开自动续费）。
7. **带宽选固定带宽**，别选按流量（被刷会账单惊魂）；顺手开「费用预警」。
